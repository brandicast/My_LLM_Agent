# Project Rules
- **Environment**: This is a WSL project. Always use Linux paths.
- **Python**: Always use the virtual environment in `.venv/`. 
- **Setup**
  * Before running any script, ensure `source .venv/bin/activate` is executed.
  * Execute `set -a` and `source .env` to load environment variables.
  * Execute `set +a` to stop loading environment variables.
- **Reference**: If you need logic details, read the files in `/reference` folder.
- **Language**: All code comments and documentation must be in Traditional Chinese.
